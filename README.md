# Pilar Agência — site

Landing page da Pilar Agência: estúdio de conteúdo e narrativa.
"A pessoa atravessa a cidade por causa de um vídeo. A gente faz esse vídeo."

## Estrutura

- `index.html` — a página inteira (HTML, CSS e JS em um arquivo)
- `videos/` — vídeos dos trabalhos: `*-loop.mp4` (prévia sem som), `*.mp4` (versão completa com áudio), `*.jpg` (miniatura)
- `designs/` — slides dos carrosséis de design
- `og.jpg` — imagem de compartilhamento · `favicon.png` — ícone da aba

## Como publicar

O site é estático, sem build. Basta servir a pasta.

- **GitHub Pages:** Settings › Pages › Source: Deploy from a branch › main / root
- **Netlify ou Cloudflare Pages:** conecte este repositório, sem comando de build, diretório de publicação na raiz
